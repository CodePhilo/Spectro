# Spectro — workflows

Generated by `python tools/workflow_screenshots.py` on the demo project (simulated spectra with realistic noise). How to apply each individual method is in the [method guide](../methods/README.md).

## 1. Import from any instrument, Excel or CSV

**Benefit:** one dialog reads text/CSV (any delimiter, decimal comma), Excel, JCAMP-DX and SPC exports; layout and names are detected and concentrations are filled from sample names — no manual re-typing.

*How:* File → Import spectra…

![Import from any instrument, Excel or CSV](01_import.png)

## 2. Organize trials, standards, mixtures and samples

**Benefit:** every spectrum lives in one project file with its trial, role and concentrations; selecting spectra plots them instantly with a λ/A readout.

*How:* Project tree + plot

![Organize trials, standards, mixtures and samples](02_project.png)

## 3. Every operation logged per spectrum

**Benefit:** the History tab lists each import, edit, processing step and calculation that touched this spectrum, with user, time and reason.

*How:* Select a spectrum → History tab

![Every operation logged per spectrum](03_history.png)

## 4. Tamper-evident audit trail

**Benefit:** append-only, hash-chained log (ALCOA+ / Part 11 style): full parameters, input/output data hashes and before/after values; any tampering is detected by Verify integrity.

*How:* Audit → Audit trail

![Tamper-evident audit trail](04_audit.png)

## 5. Processing pipelines with live preview

**Benefit:** chain smoothing, baseline, derivatives, ratio spectra and spectrum resolution; results are new derived spectra — raw data is never changed and every result can be recomputed and verified.

*How:* Process → Processing pipeline…

![Processing pipelines with live preview](05_pipeline.png)

## 6. Stacked, difference and normalized views

**Benefit:** compare many spectra at a glance; difference view shows exactly how each spectrum departs from a reference.

*How:* View selector above the plot

![Stacked, difference and normalized views](06_stacked.png)

## 7. Method optimizer — binary mixture

**Benefit:** ranks every processing strategy (zero order, derivatives, dual wavelength, ratio methods, subtraction methods, amplitude centering, absorption factor, Vierordt, bivariate, CLS, PLS) by predicted interference, noise and ±λ robustness, verified on simulated and laboratory mixtures — finds the best method in seconds instead of weeks.

*How:* Tools → Method optimizer

![Method optimizer — binary mixture](07_optimizer_binary.png)

## 8. Validation plan from the optimizer

**Benefit:** the selected method becomes an ICH Q2(R2) protocol: linearity levels over the range of your standards, accuracy and precision levels, LOD/LOQ, and robustness factors taken from the method's own settings — ready to print or export to Excel.

*How:* Tools → Method optimizer → select a row → Validation plan…

![Validation plan from the optimizer](08_validation_plan.png)

## 9. Method optimizer — ternary mixture

**Benefit:** for three overlapping drugs it shows which strategies still work and which fail, with the expected error of each; selecting an amplitude-centering row plots the ratio spectra with the wavelengths it chose.

*How:* Tools → Method optimizer (3 compounds) → select a row

![Method optimizer — ternary mixture](09_optimizer_ternary.png)

## 10. Univariate methods — 29 templates in 5 families

**Benefit:** pick a published method from the list grouped by family (zero order, derivative, ratio-derivative, ratio-amplitude, spectrum resolution), see the processed spectra and drag the λ markers to the best position.

*How:* Methods → Univariate calibration

![Univariate methods — 29 templates in 5 families](10_univariate_setup.png)

## 11. Calibration with full ICH statistics

**Benefit:** slope/intercept with SD and 95 % CI, r, Sy/x, LOD/LOQ and residual plot are computed automatically.

*How:* Calibrate

![Calibration with full ICH statistics](11_univariate_calibration.png)

## 12. Assay of mixtures and tablets

**Benefit:** found, taken and % recovery (or % label claim) with mean, SD and RSD — ready to paste into a paper or export to Excel.

*How:* Determine

![Assay of mixtures and tablets](12_univariate_results.png)

## 13. Standard addition inside the method

**Benefit:** checks accuracy in the real matrix: recovery of each spike and the extrapolated content, with the same calibrated method.

*How:* Standard addition… (spiked samples)

![Standard addition inside the method](13_standard_addition.png)

## 14. Robustness study in one click

**Benefit:** each parameter (λ, Δλ, plateau, window…) is varied by ±Δ, re-calibrated and re-assayed; the % deviation shows whether the method is robust (ICH Q2).

*How:* Robustness…

![Robustness study in one click](14_robustness.png)

## 15. Simultaneous equations (Vierordt / bivariate / AUC)

**Benefit:** classic multi-wavelength methods with the coefficient matrix, its condition number and recoveries for every compound.

*How:* Methods → Equation methods

![Simultaneous equations (Vierordt / bivariate / AUC)](15_vierordt.png)

## 16. Binary two-signal methods (Q-analysis, AS, AAS, AM, IAM, HPSAM)

**Benefit:** methods that need several signals at once, grouped by family; the isoabsorptive point is found from the standards with one click.

*How:* Methods → Binary two-signal methods

![Binary two-signal methods (Q-analysis, AS, AAS, AM, IAM, HPSAM)](16_two_signal.png)

## 17. Progressive resolution: amplitude centering

**Benefit:** AAC / MACM / RIDSS / CV-AD resolve all three drugs from ONE ratio spectrum at ONE wavelength; here with the settings the optimizer proposed. Saved like any method and applied to new samples.

*How:* Methods → Progressive resolution

![Progressive resolution: amplitude centering](17_progressive.png)

## 18. Chemometrics: cross-validation

**Benefit:** CLS, ILS, PCR, PLS, MCR-ALS, ANN and SVR with RMSECV curves and automatic choice of the number of components.

*How:* Methods → Chemometrics

![Chemometrics: cross-validation](18_chemometrics_cv.png)

## 19. Chemometrics: prediction of validation mixtures and tablets

**Benefit:** predicted-vs-actual plot, RMSEP and recoveries per compound.

*How:* Fit + predict

![Chemometrics: prediction of validation mixtures and tablets](19_chemometrics_prediction.png)

## 20. Outlier detection with T² / Q limits

**Benefit:** 95/99 % limits flag unusual calibration or sample spectra; one click excludes flagged spectra and refits. Fitted models are saved and exportable.

*How:* Outliers tab

![Outlier detection with T² / Q limits](20_chemometrics_outliers.png)

## 21. ICH Q2(R2) validation statistics

**Benefit:** linearity, LOD/LOQ, accuracy, precision/ANOVA, Student's t, F-test and the interval hypothesis test — no spreadsheet formulas to check.

*How:* Tools → Validation statistics

![ICH Q2(R2) validation statistics](21_validation.png)

## 22. Compare with a reported method from mean, SD, n

**Benefit:** t, F (one-tailed table value, as in the literature) and one-way ANOVA straight from published summary values — here Eissa 2018, Table 4 (reproduces the paper's t, F and ANOVA).

*How:* Tools → Validation statistics → Compare (mean, SD, n)

![Compare with a reported method from mean, SD, n](22_validation_summary.png)

## 23. Calibration design for multivariate models

**Benefit:** Brereton 5-level multifactor design with the volume of each stock solution to pipette — balanced, uncorrelated training mixtures.

*How:* Tools → Calibration design

![Calibration design for multivariate models](23_design.png)

## 24. Greenness assessment (AGREE, Eco-Scale, GAPI)

**Benefit:** the greenness metrics journals ask for, with the pictogram, in the same tool as the analysis.

*How:* Tools → Greenness assessment

![Greenness assessment (AGREE, Eco-Scale, GAPI)](24_greenness.png)

## 25. Publication-quality figures

**Benefit:** any plot → journal-ready TIFF/PNG (300–1200 dpi) or vector SVG/PDF/EPS, size in mm, fonts, black-and-white mode, with live preview.

*How:* Right-click a plot → Export publication figure

![Publication-quality figures](25_figure.png)

## 26. Saved methods and results, Excel export

**Benefit:** every calibration and assay is stored with its method; results export to Excel (one sheet each) and methods to portable .spmodel files.

*How:* Methods → Saved methods & results

![Saved methods and results, Excel export](26_results.png)

## 27. Edit a processing chain after the fact

**Benefit:** change any step (Δλ, smoothing window, divisor…) of processed spectra; they are recomputed from their parents, everything built on them is rebuilt, and the old versions stay archived with the reason in the audit trail.

*How:* Select processed spectra → Process → Edit processing of selected spectra… (or Lineage tab → Edit processing…)

![Edit a processing chain after the fact](27_edit_processing.png)

## 28. Edit a saved result

**Benefit:** rename, add notes, exclude a spectrum from the statistics (kept and marked), or recalculate with the current method and corrected concentrations — saved as a new version, never overwritten.

*How:* Methods → Saved methods & results → Results → Edit…

![Edit a saved result](28_edit_result.png)

## 29. Version history of a method or result

**Benefit:** every version is kept: see what changed between any version and the latest, with the reason, and restore an older one as a new version.

*How:* Methods → Saved methods & results → select → History…

![Version history of a method or result](29_history.png)

## 30. Undo a change

**Benefit:** restore the previous version of any recent edit, revision, re-processing or archiving — the undo is itself recorded in the audit trail.

*How:* Edit → Undo a change… (Ctrl+Z)

![Undo a change](30_undo.png)

## 31. Trial report with audit trail

**Benefit:** one click produces a PDF/HTML report: spectra, processing lineage, methods, results, integrity check and the audit trail.

*How:* File → Trial report

![Trial report with audit trail](31_report.png)
